## Comments

Resolved on branch `rok-sqlc-0-5-05`, in two commits: the review fixes, then the docs and 0.5.0.

**Review fixes (spec):**
- **Hidden rows count as missing (Q53).** `Feature::knows_caller` (owned, or access `user`/`admin`) decides whether a reference to an owned table uses `exists_owned`; a feature without a tenant column takes the request's `Tenant` for a reference to a tenant-scoped table. That create's or update's service method and handler gain `user`/`tenant` (`Feature::takes_caller`, `tenant_of`, `caller_of`). Public routes keep `exists_by_id` (documented in ADR 0017). Fixture: `tests/api-app/migrations/0008_scoped_checks.sql` (`bookmarks`), tests in `references.rs`.
- **Owner-column keys (Q52).** `UniqueCheck::owner`: the owner column leaves the checked columns, the read takes `owner: uuid::Uuid` and the check passes `user.id`; reported on the last other column. Fixture `folders (owner_id, name)`, test in `unique.rs`.
- **`(tenant_id, lower(name))`.** `UniqueKey::case_insensitive: bool` became `lowered: Option<String>` (`is_case_insensitive()`); the parser accepts plain columns plus exactly one `lower()` entry; lookups and `_taken` compare that column with `lower()` (`sql::equals`, `live_lookup_predicate`). `unique_key_columns` still excludes such keys. Corpus effect: four tables gain `get_by_name` (CHANGELOG). Fixture `tags`, test in `unique.rs`.
- **`mobile` without a locale** tries every carried locale (narrower than VineJS's every locale; documented).
- **`url`** is now a port of validator.js's `isURL` defaults (`is_url`): scheme optional, http/https/ftp, TLD or IP host, no `_`, port 1–65535. No `format: uri`. Test `url_checks_as_vinejs_does`.
- **`tests/api-app/src`** is gitignored and regenerated by `tests/fixture_compile` (only `lib.rs` and `features/drafts/service.rs` are checked in), so the stale copy was a local leftover; nothing to check in. The drift is covered by the fixture's tests and the OpenAPI snapshot.

**Review fixes (standards):** "pre-check(s)" wording in `shared_validation.rs`; `rule_helpers.rs` renamed `rule_snippets.rs`, its data tables split into `rule_tables.rs`; `prechecks::BodyField` shared by `exists` and `unique`; `layout::push_signature_where` and `layout::push_call` replace the private copies in `rule_functions.rs`; `sql::equals` used by lookups and `_taken`; `Feature::unique_checks` computed once beside `references`; `Bodies { create, update }` with `holds(Endpoint)` (in the new `endpoint.rs`, with `Endpoint`); the rule helpers (`Transformed`, `check`, `is_iban`, `normalize_email`, ...) and their tables are written once into `shared/validation.rs`, `pub`, and each `dto.rs` imports what it calls; `FieldFailures::is_empty` removed; `api_rules` tests moved to `src/api_rules/tests.rs`. Every source file is under 600 lines.
